# Selected source files for the November Collatz integration study

These files were fetched for read-only inspection from
[Idris Ali Shaik's CollatzConvergencePositiveDensity](https://github.com/shaikidris/CollatzConvergencePositiveDensity)
at commit `f0fda887ee60dc8ac4ef0d864935148b03734726`.

The selection is incomplete and is not a buildable dependency. No downloaded
code was executed or compiled. `manifest.json` records immutable raw URLs,
SHA-256 hashes and byte sizes. The original source headers, Apache-2.0 license,
and applicable upstream Mazur notices are retained. The manuscript was not
copied.

Local integration uses independently written proofs in the existing project,
with attribution to the finite root-pool and allocation mechanisms inspected
here. No external analytical theorem is adopted by this source archive.
