Version 7.0.0 — technical continuation of the phantom-shadowing programme. This English manuscript reports finite arithmetic results, paper proofs, and a source-bound verification record. It does not claim a proof of the Collatz conjecture.

The finite core gives an explicit reciprocal budget 133547/1655 < 81 for every finite injective shortcut trajectory, a first-arrival correction-product bound of exp(27), and height constraints on existing inverse-word transports. A quadratic occupation estimate covers repeated sources and cyclic targets and implies finiteness of bounded-slope inverse catalogues. The resulting time bound is existential; it is not an effective search cutoff. Prior qualitative reciprocal/product bounds and antecedent counting methods are explicitly credited.

A separate conditional argument pays finite prefix-free off-path catalogues from one stated external lower logarithmic-density input, including a possible entry into a cycle. The external input is not a theorem imported into the local Lean development. A paper-level paired-path construction composes two classical word rules with an attributed terminal merger, proves that a minimum divergent unit seed must leave the resulting language, and derives exact charges for several exits. Universal exit coverage and global amortization remain open.

The PDF includes self-contained proofs, nineteen references, a comparison with version 6, and explicit distinctions between Lean-checked declarations, paper proofs, finite arithmetic checks, external results, and open obligations. The supplementary ZIP contains the complete canonical package of ninety Lean source files, pinned build files, the English manuscript sources and audits, selected strict dependency-audit programs and fresh outputs, and a reproducible archive builder with a SHA-256 manifest. It excludes build caches and third-party manuscripts.

The build uses Lean and Mathlib 4.29.1. Selected arithmetic declarations use only the three recorded standard axioms; older parts of the full library additionally use documented native computation assumptions. This pinned toolchain predates later published kernel soundness fixes. Acceptance by the pinned checker is reported honestly; an independent replay under a current checker has not been performed. AI assistance and shared-context review are disclosed and are not represented as independent human peer review.
